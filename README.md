🔢 MNIST Digit Classifier

A neural network was trained using the MNIST handwritten digit dataset.

Dataset
Training images: 60,000
Testing images: 10,000
Image size: 28 × 28 pixels
Number of classes: 10 (digits 0–9)
Pixel values normalized to the range 0–1
Model Architecture
Input Image (28 × 28)
        ↓
Flatten
        ↓
Dense Layer (128 neurons)
        ↓
Dense Layer (10 neurons)
        ↓
Digit Prediction (0–9)
Training
Epochs: 5
Optimizer: Adam
Loss: Sparse Categorical Crossentropy
Results
Metric	Result
Training Accuracy	98.54%
Validation Accuracy	97.72%
Test Accuracy	97.64%
Test Loss	0.0771

The trained model was successfully saved as:

models/mnist_model.keras

outputs/mnist_prediction.png
▶️ How to Run

Activate the virtual environment:

.\.venv\Scripts\Activate.ps1

Install dependencies:

python -m pip install -r requirements.txt

Run TensorFlow basics:

python main.py

Run tensor basics:

python tensor_basics.py

Run the MNIST classifier:

python mnist_classifier.py

🎯 Object Detection Pipeline

The implemented pipeline follows these steps:

Input Image
     ↓
Pretrained YOLO Model
     ↓
Object Detection
     ↓
Class + Confidence Score
     ↓
Bounding Boxes
     ↓
Annotated Output Image
🤖 YOLO Object Detection

A pretrained YOLO11n model was used to perform object detection on an input image.

The model automatically identifies objects and predicts:

Object class
Confidence score
Bounding box coordinates
Example Detection

For the sample bus.jpg image, the model detected:

Object	Confidence
Bus	94.02%
Person	88.82%
Person	87.83%
Person	85.58%
Person	62.19%

Overall, the model detected:

4 persons and 1 bus.

📊 Detection Output

The annotated detection result is saved as:

outputs/yolo_detection.jpg

The output image contains bounding boxes, object labels and confidence scores generated by the YOLO model.

🧪 OpenCV Bounding Box Demonstration

An additional OpenCV-based demonstration was implemented to understand the concept of drawing bounding boxes around objects.

The output is saved as:

outputs/detection_output.jpg

This demonstration helped understand the visualization aspect of object detection before implementing the pretrained YOLO detector.

▶️ How to Run

Activate the virtual environment:

.\.venv\Scripts\Activate.ps1

Install the required dependencies:

python -m pip install -r requirements.txt

Run the OpenCV bounding-box demonstration:

python object_detection.py

Run YOLO object detection:

python yolo_detection.py

The first YOLO run automatically downloads the pretrained model if it is not already available locally.
